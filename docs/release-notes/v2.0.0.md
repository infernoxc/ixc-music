**IXC Music 2.0** adds a per-platform music switch and Spotify / YouTube link support, and moves everything into one small native background program, **IXC Core**.

### Highlights
- **Music goes to: ALL · TWITCH ONLY · KICK ONLY · YOUTUBE ONLY.**
  - One click switches the OBS audio tracks of the music source through OBS's built-in obs-websocket, and IXC reads them back to confirm (a few milliseconds).
  - Saved and re-applied when OBS starts, and manual changes in OBS are detected.
  - The platform → track map is configurable (default Twitch 1, Kick 2, YouTube 3).
- **Links:**
  - YouTube videos, Shorts, YouTube Music and playlists, checked first with YouTube's official oEmbed service;
  - **Spotify songs**, matched to the same song on YouTube;
  - **Spotify playlists and albums**, with your own free Spotify developer app.

  Private, deleted, duplicate and unsupported links get a clear message.
- **Phone remote from anywhere** (mobile data too): now playing, controls, volume, destination switch, add songs, queue.
- **Diagnostics page** at `http://localhost:8767/diag`.
- The player and docks get updates **pushed** instead of polling.

### Measured (Windows 11, OBS 32.2.2, 60-second test with the usual OBS pages open)
| | CPU | RAM | Requests from OBS pages |
|---|---|---|---|
| v1.0.0 (PowerShell helper, polled) | 0.065 % | 152 MB* | ~260 polls/min |
| **v2.0.0 (IXC Core)** | **0.011 %** | **42 MB*** | a push every 5 s while music plays |

\* IXC Music + IXC ChatBox together (they share one background program).

### Upgrading from v1
Close OBS and run the new installer. Your settings, queue and OBS URLs stay the same.
For the destination switch, enable OBS › Tools › WebSocket Server Settings and keep the source name *IXC Music Player* (or set `music.routing.inputName`).

### Known limitations
- Spotify audio can't be played in OBS. IXC plays the YouTube match instead; without Spotify keys the match uses the title only.
- Spotify doesn't give apps its own editorial or algorithmic playlists, or private playlists.
- YouTube search and "similar songs" read YouTube's public pages (an optional official YouTube Data API key covers search). They can break when YouTube changes.
- Age-restricted and region-blocked videos pass the link check, but are skipped with the reason when they come up.
- The switch controls which OBS tracks carry the music. Which track reaches which platform is set in your OBS outputs.
