## IXC Music v1.0.0: first public release

A free, lightweight **YouTube music player for OBS Studio**: search and queue from an OBS dock, and play through a normal
OBS audio source, so you choose which audio tracks carry the music.

### Features
- Search YouTube from inside OBS (no API key), or paste a video / playlist link
- Queue: play now, add, move up, remove, and jump to any song
- Shuffle, repeat, and **autoplay** of similar songs when the queue ends
- Optional **start with OBS**, which resumes the last song at the saved position
- Recovers from unexpected pauses; skips blocked or removed videos and shows the reason
- Per-user installer (no admin), start at login, Start menu shortcuts, clean uninstaller

### Downloads
| File | Use |
|---|---|
| `IXC-Music-Setup-v1.0.0.exe` | Installer (recommended for most people) |
| `IXC-Music-v1.0.0.zip` | Portable package: unzip, then double-click `Install.bat` |
| `SHA256SUMS.txt` | Checksums: `Get-FileHash <file> -Algorithm SHA256` |

**Install:** close OBS, run the installer, then add the browser source `http://localhost:8767/music/player.html` and the dock
`http://localhost:8767/music/dock.html`. Step-by-step: [docs/INSTALL.md](https://github.com/infernoxc/ixc-music/blob/main/docs/INSTALL.md)

### Supported versions
Windows 10/11 and OBS Studio 30+. **Tested on Windows 11 (build 26200) with OBS Studio 32.2.2.**

### Known issues
- Search and autoplay read YouTube's public pages (no official API is used), so they can break if YouTube changes those pages.
  Pasting links still works.
- Some videos can't be played in embedded players (owner restriction); they're skipped with a message.
- The files aren't code-signed, so Windows SmartScreen may warn you. Choose *More info › Run anyway* for files from this page only.
- Stream only music you're allowed to use (for example NCS, StreamBeats).
